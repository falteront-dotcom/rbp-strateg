# Дайджесты РБП-Стратег (еженедельные)

Еженедельная аналитическая сводка по модели БП 3.0: топ-10 рейтинга с
интервалами P10–P90, самые неопределённые соседние пары рейтинга,
лента мониторинга, методология. Дайджест — проверка спроса контентом
(путь B дорожной карты 2026-11-13: продукт без новой инфраструктуры).

## Как генерируется

```
npm run db:seed                       # свежая БД (если нужно)
npx tsx src/scripts/generate-digest.ts
```

Скрипт собирает данные через фасад v3 (`getBP3Ranking`, `getAlertsFeed`)
и пишет `digest-<дата>.md`. Все числа — из текущей БД; при пустых алертах
раздел честно сообщает, что правил не сработало.

Страница `/v3/digest` рендерит свежий срез по тем же выборкам
(`src/lib/digest/generator.ts` — общий вход для Markdown и страницы),
этот каталог — история выпусков.
