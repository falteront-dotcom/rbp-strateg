# Track: bp-model — 8-компонентная модель боевого потенциала

## Spec

Спроектировать и реализовать математическую модель расчёта боевого потенциала государства по 8 компонентам военной науки. Модель должна основываться на открытых данных и коррелировать с авторитетными рейтингами (Global Firepower > 0.85).

## Компоненты модели

### 1. W — Оружие и техника (Weight: 0.20)
```
W = f(количество_ВВТ, качество_ВВТ, возраст_парка, ядерный_потенциал)
```
- Количество: танки, самолёты, корабли, ПВО, артиллерия
- Качество: tech_level × количество (из текущего unit-database)
- Возраст: средний возраст парка (модернизация = молодой парк)
- ЯО: бинарный × количество боеголовок × дальность носителей

### 2. M — Человеческий ресурс (Weight: 0.15)
```
M = f(численность_ВС, резерв, выучка, моральный_дух)
```
- Численность: активный персонал + резерв
- Выучка: часы налёта (авиация), боевой опыт (лет участия в конфликтах)
- Моральный дух: экспертная оценка 1-10

### 3. L — Логистика (Weight: 0.12)
```
L = f(флот_логистики, порты, аэродромы, топливо, ремонт)
```
- Транспортный флот, танкеры, грузовики
- Количество морских портов, аэродромов
- Нефтедобыча/импорт топлива
- Ремонтные мощности

### 4. C2 — Управление и связь (Weight: 0.10)
```
C2 = f(АСУ, РЭБ, разведка, ЦУР, спутники)
```
- Автоматизированные системы управления
- РЭБ-возможности (наличие/мощность систем)
- Разведка: спутники, ДРЛО, радиоэлектронная разведка
- Цифровое управление battlefield

### 5. E — Экономика (Weight: 0.15)
```
E = f(ВВП, военный_бюджет, ВПК, импорт_оружия)
```
- ВВП (ППС) — база
- Военный бюджет — текущие инвестиции
- Мощность ВПК — способность производить своё оружие
- Импорт/экспорт оружия — зависимость/влияние

### 6. D — Доктрина (Weight: 0.08)
```
D = f(боевой_опыт, стратегия, обучение, модернизация)
```
- Боевой опыт: участие в конфликтах за последние 10 лет
- Стратегия: ядерное сдерживание / экспедиционная / оборонительная
- Качество обучения: расходы на подготовку на 1 военнослужащего
- Темп модернизации: % нового оружия за последние 5 лет

### 7. R — Боеготовность (Weight: 0.10)
```
R = f(мобилизационный_ресурс, время_развёртывания, боекомплект)
```
- Мобилизационный ресурс: население призывного возраста
- Время развёртывания: скорость мобилизации
- Боекомплект: запасы на 30/60/90 дней войны

### 8. T — География (Weight: 0.10)
```
T = f(территория, выход_к_морю, ключевые_проходы, климат)
```
- Площадь территории (чем больше — тем сложнее захватить)
- Выход к морю / количество береговой линии
- Контроль ключевых проливов/проходов
- Климат: суровый климат = преимущество обороны

## Формула

```
BP = W×0.20 + M×0.15 + L×0.12 + C2×0.10 + E×0.15 + D×0.08 + R×0.10 + T×0.10
```

Каждый компонент нормализуется в [0, 100] относительно максимума среди всех стран.
