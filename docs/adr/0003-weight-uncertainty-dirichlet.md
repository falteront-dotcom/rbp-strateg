# ADR-0003: Неопределённость весов — Dirichlet(κ=100) в Монте-Карло

Дата: 2026-11-14
Статус: **принято, реализовано** (PR #18, `e2e/bp3-weight-uncertainty.spec.ts`)

## Контекст

Веса БП 3.0 (`DEFAULT_WEIGHTS_BP3`, `src/lib/bp3/types.ts`) — экспертные, не
калиброванные по исходам (происхождение и процедура пересмотра —
docs/weights-elicitation.md). До PR #18 Монте-Карло варьировал только входные
данные компонентов (σ по грейду провенанса A–E), веса были константами:
интервалы P10/P90 систематически занижали неопределённость итога — главная
неопределённость модели (выбор весов) в них не попадала.

Калибровка весов по GFP отвергнута как циркулярная (GFP — сам композит с
закрытыми весами); по конфликтным исходам — несостоятельна при ~10–15
межгосударственных войнах с 1990 г. (подробно — docs/weights-elicitation.md).

## Решение

На каждой итерации Монте-Карло веса тянутся из
Dirichlet(α_i = w_i × κ), κ = `DEFAULT_WEIGHT_CONCENTRATION` = 100
(`src/lib/bp3/calculate-bp3.ts`):

- сумма весов всегда 1, среднее равно экспертным весам;
- дисперсия w_i(1−w_i)/(κ+1); для weapon 0.16 это σ ≈ 0.036 (±23 % относительной);
- κ = 0 отключает тягу весов — прежнее поведение, для сравнения.

Следствия для публикуемых метрик (реализованы в `src/lib/v3-facade.ts`):
P10/P90 итога покрывают весовую неопределённость; rank-stability когорты
считается по сырым итерациям (`keepSamples`, сид страны не зависит от когорты —
парные сравнения итерация-в-итерацию корректны): интервал ранга P10–P90 и
P(выше соседа по медиане).

## Последствия

**Плюсы:** интервальный итог честен относительно статуса весов («экспертные»);
ключевой замер — P(USA выше CHN) ≈ 0.65: топ рейтинга статистически неразличим,
и это публикуемый результат, а не скрытый дефект; места в рейтинге перестают
выглядеть точками.

**Минусы/риски:** интервалы шире — «некрасивые» цифры на витрине; стоимость
rank-stability O(iters × N log N) — платится один раз на процесс в кэше фасада;
κ=100 — методическая константа, не выведенная из данных (задокументировано).

Замечание: LOO-диагностика (PR #19, `docs/diagnostics/loo-ranks-2026-11-13.md`,
ρ ≥ 0.991) показала, что рейтинг сильнее зависит от коррелированных компонентов
v2-ядра, чем от отдельных весов, — весовая неопределённость необходима, но не
достаточна; пересмотр структуры ядра — отдельная задача пути «Глубина».
