# Track: map-foundation — Реальная карта мира

## Spec

Заменить стилизованную HolographicMap (SVG-сетку) на полноценную интерактивную карту мира на базе Mapbox GL JS + Deck.gl + react-map-gl. Карта должна:
- Отображать реальную географию (границы, рельеф, океаны)
- Поддерживать choropleth-раскраску стран по боевому потенциалу
- Иметь стилизацию под военный HUD (тёмная тема, cyan-акценты)
- Работать как фундамент для стратегического и тактического режимов

## Acceptance Criteria

1. Карта загружается < 2 сек
2. Choropleth отображает все страны с цветовой кодировкой
3. Клик по стране выделяет её и возвращает ISO-код
4. Hover показывает popup с названием и краткими данными
5. Зум/пан/вращение работают плавно
6. Стилизация в военном HUD стиле (тёмная тема, cyan)
