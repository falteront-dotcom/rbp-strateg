# Workflow — РБП-Стратег 2.0

## Методология

**Контекстно-ориентированная разработка** с TDD-циклом для критических модулей.

## Фазы развития

### Phase 1: Фундамент карты и модели БП
- Установка mapbox-gl, react-map-gl, deck.gl, @turf/turf, d3-scale, d3-geo
- Создание модели боевого потенциала (8 компонент)
- База данных стран с Drizzle ORM
- Базовая карта мира с choropleth
- Карточка государства

### Phase 2: Стратегическая аналитика
- Аналитические слои (бюджет, численность, ЯО, флот, авиация)
- Сравнение стран (до 4)
- Коалиционный анализ
- Радарные диаграммы и тренды

### Phase 3: Тактический симулятор на реальной карте
- Юниты на Mapbox карте (маркеры с MilStd icon)
- Зоны поражения ПВО/авиации (круги, полигоны)
- Логистические линии и маршруты
- Миграция rbp-engine на реальные координаты
- Баллистическая модель на реальной карте

### Phase 4: Интерактив и полировка
- Редактирование зон (@nebula.gl)
- Экспорт отчётов
- Мультиязычность (RU/EN)
- Оптимизация производительности

## Git-конвенции

```
feat(<scope>): <subject>

<body>

Track: <track-id>
```

Scope: `map`, `bp-model`, `db`, `ui`, `tactical`, `analytics`

## Quality Gates

- TypeScript strict mode — без `any`
- Linting: `npm run lint` без ошибок
- Playwright тесты для ключевых флоу
- Карта загружается < 2 сек
- 60 FPS при 100+ юнитах в тактическом режиме

## Запуск

```bash
npm run dev          # Разработка
npm run lint         # Линтинг
npx playwright test  # Тесты
npm run build        # Сборка
```
