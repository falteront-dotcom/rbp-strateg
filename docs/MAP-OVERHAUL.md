# Переработка стратегической карты

## Локальный атлас (обновление)

Без настроенного Mapbox-токена `StrategicMap` теперь показывает `StrategicAtlas`, а не инструкцию настройки. Это отдельная 2D SVG-карта на d3-geo с локальным `/data/countries.geojson`; WebGL, внешние тайлы и ключи не нужны. При корректном по формату токене используется прежняя Mapbox-ветка.

- Шесть тематических заливок, легенда с единицами, рейтинг и карточка страны.
- Линейная шкала БП и явно подписанная логарифмическая шкала остальных величин; ноль отличается от отсутствия данных.
- Поиск (русское/английское название и ISO), масштабирование, перетаскивание, региональные пресеты, переключение подписей и выбор с клавиатуры.
- Полноэкранный режим с переключением тематических слоёв; выход кнопкой или Escape. Если Fullscreen API недоступен, используется CSS-разворачивание.
- Поиск поддерживает стрелки, Enter, Escape и ARIA combobox/listbox.
- Кнопка центрирования выбранной страны и приближение двойным кликом.
- Подписи сохраняют экранный размер при масштабировании; число кандидатов растёт с приближением, пересечения и области под HUD исключаются. Это детализация подписей, а не обновление геометрии Natural Earth.
- Для стран без полигонов, но с известными координатами (например, Сингапура), показываются условные выбираемые маркеры.
- ISO геометрии нормализуются, но callback сохраняет исходный ключ API (например, `PHI`).
- Панель подробностей появляется только после выбора; на узких экранах открывается снизу.
- При ошибке загрузки границ предусмотрена повторная попытка.
- Нет фиктивного LIVE-статуса: интерфейс сообщает, что данные не обновляются в реальном времени.

Проверка локального режима (нужен запущенный сервер без Mapbox-токена):

```bash
python scripts/test-map.py http://localhost:3000
```

На Windows тест использует установленный Edge через Python Playwright. Проверяет геометрию, выбор клавиатурой, zoom/reset, пять дополнительных слоёв, alias Филиппин, мобильную панель, отсутствие JS-ошибок и восстановление после HTTP 503 геоданных. Скриншоты сохраняются в `test-results/atlas/`.

Ограничения: локальная карта — 2D, без спутниковых снимков и 3D-рельефа; точность границ ограничена Natural Earth 110m. Mapbox-ветка с действующим токеном в этой итерации браузером не проверялась. Историческое описание ниже относится главным образом к ней.

## Полный мировой охват и стратегические объекты

База данных расширена с 59 до **195 государств** (Филиппины — одна запись под legacy-ключом PHI; canonical PHL принимается как алиас во всех API).

Достоверность данных — трёхслойная:

1. **Программный слой** (`scripts/build-world-data.py`): World Bank API (ВВП ППС, население, военные расходы SIPRI, площадь — полная пагинация) + mledoze/countries (ISO2, столицы/координаты, регионы, площадь, landlocked).
2. **Исследовательский веер** (18 агентов GLM-5.3 через pi workflow): военные инвентари 137 стран (GFP/IISS) и 150 военных баз/стратегических объектов по 10 регионам мира.
3. **Генераторы с валидацией** (`scripts/build-facilities.py`): типы, координаты, ISO-хостов, дедупликация; территориальные зависимости (SHN/GIB/GRL) нормализуются к суверенам.

Новые API-маршруты:

- `GET /api/facilities` — 145 объектов; фильтры `?type=` (10 типов), `?iso=` (хост), `?operator=`, `?minValue=`.
- `GET /api/countries/[iso]` — профиль государства: данные БП + `hostedFacilities` + `operatedFacilities`; PHI/PHL алиасы; 404 для неизвестных кодов.

Слой объектов на карте (SVG, поверх любой тематической заливки):

- 10 типов с собственными символами и приглушёнными функциональными цветами (авиабаза, ВМБ, сухопутная, ракетный, РЛС/СПРН, космический, ядерный, разведка/РЭБ, логистика, проливы).
- Прореживание по значимости на мировом зуме + пространственная декластеризация (в кластере остаётся важнейший объект; остальные появляются при приближении) — маркеры не перекрывают друг друга и всегда кликабельны.
- Z-порядок по возрастанию значимости: важнейшие объекты сверху.
- Карточка объекта: тип, хост, оператор, значимость 1–10, описание, источник. Кнопка-переключатель слоя в тулбаре.

Проверки: `test-map.py` (195 стран в сайдбаре, ≥20 маркеров, карточка объекта, toggle, все прежние сценарии), `audit-ui.py`, `audit-all-surfaces.py`, полный lint/typecheck/build — всё PASS.

Ресид БД: `POST /api/init-db` с заголовком `x-admin-token` (значение `RBP_ADMIN_TOKEN` из `.env.local`). Ожидаемый ответ: `{"ok":true,"countriesSeeded":195,...}`.

## Интерфейсный проход avoid-ai-design

Весь frontend проверен в dashboard-профиле skill `avoid-ai-design` и приведён к направлению «оперативный стол»:

- IBM Plex Sans и Plex Mono вместо единственного дефолтного Inter;
- матовые графитовые поверхности вместо повсеместного glassmorphism;
- цвет используется для данных, выбранного состояния и предупреждений, а не для декоративного glow;
- удалены gradient-текст, blur-пятна, случайные hover-scale и крупные одинаковые радиусы;
- минимальный видимый кегль, включая подписи Recharts и SVG, поднят до 10 px;
- детали выбранной страны показываются в одной панели: карточка карты не дублирует правую аналитику;
- десять аналитических разделов размещены в двухрядной сетке без горизонтальной прокрутки;
- сценарный What-If получил отдельный встроенный режим и больше не перекрывает соседние вкладки;
- коалиции и сравнение получили семантику dialog и закрытие по Escape;
- исправлено общее преобразование alpha-3 ISO в флаги (`USA` больше не превращается в флаг Швейцарии);
- тактический режим получил координатную сетку и явное пустое состояние с первым действием.

## Что изменилось

Карта РБП получила единый интеграционный слой поверх Mapbox GL и DeckGL 9. Публичные контракты `StrategicMap`, `ChoroplethLayer` и аналитических builder-функций сохранены; `src/app/page.tsx` продолжает передавать прежние `countryBPData`, `countriesRaw` и `selectedISO`.

### Визуализация БП

- BP-хороплет использует реальные значения через домен `[minBP, maxBP]`, без повторной нормализации.
- Палитра проходит в OKLCH через `src/lib/geo/oklch.ts`: глубокий синий → cyan → amber → coral.
- Легенда и DeckGL используют одну и ту же палитру, поэтому подписи и заливки не расходятся.
- Страны без BP отображаются приглушённым no-data стилем и не получают высоту.
- 3D-высота полигонов зависит от BP с ограниченным нелинейным усилением верхнего диапазона.
- Выбранная страна получает золотую границу, hover — cyan-подсветку; остальные страны мягко приглушаются.
- ISO-коды нормализуются одинаково во всех слоях: пробелы, регистр, `PHI → PHL`, `KOS/KSV → XKX`, sentinel `-99`.

### Аналитические слои

- Бюджет остаётся географическим GeoJSON-слоем с extrusion и корректным сопоставлением ISO.
- Флот использует `ArcLayer` к географическим региональным кластерам и 2.5D-колонки для агрегированных значений.
- Авиация, бронетехника и ядерный арсенал используют 2.5D `ColumnLayer` вместо непрозрачных scatter-кругов.
- Для близких стран выполняется географический binning, что уменьшает визуальный шум, сохраняя список ISO участников кластера.
- Все слои pickable, поддерживают hover/click callbacks, auto-highlight и плавные DeckGL transitions.
- `getAnalyticsLayerLegend()` отдаёт динамические min/max, единицы и цвета для будущих HUD-легенд.

## Сопоставление с подходами Osiris

В карте сохранены и усилены типовые сильные стороны карт Osiris-подобного класса:

- choropleth по стране вместо плоской таблицы;
- интерактивный hover/click drill-down;
- переключение аналитических тематических слоёв;
- 3D-экструзия и пространственные связи для быстрого чтения масштаба;
- географические кластеры для плотных наборов данных.

Превышение исходного уровня достигается за счёт:

- перцептивно более равномерной OKLCH-палитры и согласованной легенды;
- отдельного no-data состояния вместо ложного нулевого значения;
- иерархии selected/hover/обычная граница;
- динамических min/max и единиц в analytics metadata;
- русской UI-локализации;
- устойчивой ISO-нормализации, включая Natural Earth fallback-поля и Kosovo/Philippines aliases;
- безопасного fallback без токена Mapbox, при котором боковые панели и BP-аналитика продолжают работать.

## Токен Mapbox

1. Создайте публичный токен в [Mapbox Access Tokens](https://account.mapbox.com/access-tokens/).
2. В корне проекта создайте `.env.local`:

```env
NEXT_PUBLIC_MAPBOX_TOKEN=pk.eyJ1Ijo...
```

3. Перезапустите dev-сервер после изменения `.env.local`.

Токен не должен попадать в git. Если переменная отсутствует или не проходит проверку формата, включается локальный `StrategicAtlas`. Список стран, BP-модель и панели аналитики также не требуют Mapbox-токена.

- Вкладка **«ОПК»**: компании, поставки, договоры, учения, миротворчество.
- **«Вооружение»**: парк техники, ракеты/ПВО/флот, образцы ВВТ с ТТХ, боевой порядок.
- **«География»**: страновое досье (overview/геополитика/структура ВС/факты).
- **«Экономика»**: реальные показатели World Bank с атрибуцией.

### Достоверность и анти-ИИ

- Оценки округлены, помечена неопределённость; реальные данные разделены с оценками и подписаны.
- Анти-ИИ дизайн: 0 эмодзи, без глассморфизма/градиентов/декоративных теней; честные матовые поверхности; `tabular-nums`; минимальный шрифт 10px (проверяется `scripts/audit-layout.py`).

### Инструменты качества и экспорт

- `scripts/audit-knowledge.py` — 164 проверки целостности стека знаний (API → БД → данные): счётчики, ISO, enum-значения, диапазоны координат, честные empty-состояния.
- `scripts/test-knowledge-ui.py` — функциональный тест секций знаний во вкладках (сражения/кампании, браузер ВВТ с фильтрами, досье, агрегаты аналитики).
- `src/lib/export.ts` — клиентская выгрузка справки по стране: CSV (RFC 4180) и JSON с разделением источников; кнопки CSV/JSON в шапке панели страны.
- `src/components/viz/Sparkline.tsx` — переиспользуемый мини-график тренда (плотность данных без чарт-библиотек).
