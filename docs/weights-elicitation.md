# Происхождение весов БП (elicitation)

Статус: **экспертные веса, не калиброванные по исходам**. Пометка «calibrated»
в коде до ноября 2026 не имела источника и убрана (шаг 2 дорожной карты,
пузырь 2026-11-13). Этот документ — источник происхождения весов и процедура
их пересмотра.

## Веса v2 (`src/lib/bp/weights.ts`, заморожены как контракт)

| Компонент | Вес | Обоснование |
|---|---|---|
| W — оружие | 0.20 | Платформенная огневая мощь — традиционное ядро военных балансов (IISS Military Balance, GFP) |
| M — люди | 0.15 | Активный состав + резерв + качество; без людей техника не воюет |
| E — экономика | 0.15 | ВВП и военный бюджет как база воспроизводства силы (SIPRI Milex) |
| L — логистика | 0.12 | Порты, аэродромы, нефть, торговый флот — проекция и sustainment |
| C2 — управление | 0.10 | C4ISR, РЭБ, технологический уровень — множитель, не платформа |
| R — боеготовность | 0.10 | Резерв/актив, обученность, мораль |
| T — география | 0.10 | Площадь, побережье, сухопутность — оборонительная глубина |
| D — доктрина | 0.08 | Стратегическая культура, опыт конфликтов |

Методологическая рамка: военная наука (Энциклопедия РВСН, SIPRI, Creveld —
см. README). Конкретные значения — экспертное решение автора проекта,
не результат fitting'а. Сумма строго 1.0 (валидация `validateWeights`).

## Веса v3 (`DEFAULT_WEIGHTS_BP3`, `src/lib/bp3/types.ts`)

Перебалансировка относительно v2 задокументирована в коде: доля платформенных
компонентов снижена (weapon 0.20 → 0.16), высвобожденные 0.20 отданы новым
компонентам U (БПЛА, 0.10) и P (боеприпасы, 0.10) — факторы, которые война
2022–2026 гг. показала решающими. Это тоже экспертное решение, не калибровка.

## Почему НЕ калибруем по GFP/SIPRI (решение экспертов пузыря)

1. **Циркулярность целевой переменной.** GFP PowerIndex — сам композит из 60+
   факторов с закрытыми редакционными весами. Подгонять наши веса к его рангам —
   переоткрывать чужие экспертные веса через чужую агрегацию.
2. **Несвобода входов.** Часть входов модели (techLevel, moraleIndex,
   combatExperience…) — ручные шкалы, уже встроенные в расчёт компонентов;
   регрессия на GFP выучила бы подгонку, вшитую в данные.
3. **Несовпадение покрытия и предмета.** GFP ранжирует ~145 стран и исключает
   ядерное оружие; модель покрывает 195 и включает nuclearWarheads. SIPRI Milex —
   затраты (вход economy), а не исход.
4. **Конфликтные исходы не идентифицируют веса.** Межгосударственных войн с
   1990 — порядка 10–15; selection bias, confounders (коалиции, ядерный зонтик,
   resolve) и грубость исхода дают доверительные интервалы на весь симплекс.
   Калибровка «по войнам» выглядит строго и не несёт информации.

Внешние ранги (GFP) остаются **диагностикой**, не калибровкой: Spearman по всем
странам с данными GFP ищет аномальные расхождения (вопрос к данным или весах) —
`src/scripts/diagnostics/spearman-gfp.ts`.

## Как весовая неопределённость учтена сейчас

Веса тянутся из Dirichlet(α_i = w_i × κ) на каждой итерации Монте-Карло
(`src/lib/bp3/uncertainty.ts`, `DEFAULT_WEIGHT_CONCENTRATION = 100`):
сумма всегда 1, среднее равно экспертным весам, дисперсия w_i(1−w_i)/(κ+1).
Для weapon 0.16 это σ ≈ 0.036 (±23% относительно). P10/P90 итога и rank-stability
(интервал ранга, P(выше соседа)) покрывают весовую неопределённость, а не только
разброс входных данных. κ = 0 отключает (старое поведение, интервалы уже).

## Процедура пересмотра (когда появится основание)

1. **Экспертная elicitation** — основной путь: BWM (Best–Worst Method, Rezaei
   2015: 2n−3 = 13 сравнений на 8 критериев) или Дельфи (3–4 анонимных раунда,
   сходимость по стягиванию IQR) для D/R/доктрины, где данные не разделяют
   компоненты. Результат — веса с интервалами, α Dirichlet по уверенности.
2. **Данные-веса** — только при появлении подлинных исходов: Bradley–Terry на
   диадных исходах COW MID 5.0 с двухступенчатой моделью (onset → outcome,
   selection bias по Reed 2000 / Fearon 2002), эпоховые эффекты, walk-forward
   holdout (AUC/Brier, не p-value). Экспертные веса — байесовский априор.
3. **Приёмка**: fitted-веса прогоняются через OAT ±20% и вклад в дисперсию
   (`sensitivity.ts`); критерий — топ-20 состава рангов не меняется. Версия
   весов в git + отчёт калибровки (датасет, окно, holdout-метрики) в docs/.
   Текущие экспертные DEFAULT_WEIGHTS остаются фолбэком.
